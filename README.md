# Lego-Style-Content

Blocky 3D story reels (1080×1920, ~2 min) built locally: Remotion + Three.js for the
picture, VoiceLab for the voice, ffmpeg for the sound. See CLAUDE.md for the workflow
and the style.

```bash
npm install
cp .env.example .env   # add VOICELAB_API_KEY
make all STORY=green-fog LANG=en
```
